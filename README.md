# WTTG2 RU

WTTG2 Russian translation mod.

Русский перевод для Welcome to the Game II (Unity 2017.3, Windows x64). Поддержка кириллицы, перевод интерфейса, сайтов и субтитров. Это предварительный выпуск: часть текста остаётся английской, озвучка исходная. Полного прохождения и независимой проверки перевода человеком не было.

## Установка и использование

Используйте готовые архивы в разделе Releases. Основной пакет требует проверенную совместимую английскую версию игры.

Скачайте WTTG2-RU-0.3.0-RC.zip из Releases, распакуйте и запустите WTTG2-RU-Setup.exe. Укажите папку игры. Установщик проверяет исходные файлы и сохраняет резервную копию. Для возврата английского языка используйте действие восстановления в установщике.

После основного перевода можно установить дополнение WTTG2-RadioSubtitles-RU-1.0.0.zip из того же релиза: разборчивые фрагменты в 12 записях переведены, 7 записей отмечены как неразборчивые. Проверка двумя локальными ASR-моделями, без ручного прослушивания; ошибки возможны. Порядок: основной пакет, затем дополнение рации.

## Проверка

Для основного пакета проверены установка/откат и 10 сценариев Unity UI. Для дополнения рации прошли 56 проверок загрузки, таймингов и состояния интерфейса; остальные 190 строк субтитров сохранены. Эти проверки не заменяют полный игровой сеанс.

Проверено на Windows x64, Unity 2017.3. Для BepInEx-плагинов используется BepInEx 5.4.23.5. Совместимость с другими версиями игры не гарантируется.
