# WTTG2 RU — Welcome to the Game II

Partial Russian translation for Welcome to the Game II (WTTG2): menus, websites and subtitles. English audio.

**Скачать:** [готовые файлы](https://github.com/x1pee/wttg2-ru/releases/tag/v0.3.1-rc).

Русский перевод для Welcome to the Game II (Unity 2017.3, Windows x64). Поддержка кириллицы, перевод интерфейса, сайтов и субтитров. Это предварительный выпуск: часть текста остаётся английской, озвучка исходная. Полного прохождения и независимой проверки перевода человеком не было.

## Установка и использование

Используйте готовые архивы в разделе Releases. Основной пакет требует проверенную совместимую английскую версию игры.

Скачайте WTTG2-RU-0.3.1-RC.zip из Releases, распакуйте и запустите WTTG2-RU-Setup.exe. Укажите папку игры. Установщик проверяет исходные файлы и сохраняет резервную копию. Для возврата английского языка используйте действие восстановления в установщике.

После основного перевода можно установить [дополнение субтитров рации 1.0.0](https://github.com/x1pee/wttg2-ru/releases/download/v0.3.0-rc/WTTG2-RadioSubtitles-RU-1.0.0.zip): разборчивые фрагменты в 12 записях переведены, 7 записей отмечены как неразборчивые. Проверка двумя локальными ASR-моделями, без ручного прослушивания; ошибки возможны. Порядок: основной пакет, затем дополнение рации. Перед возвратом английского сначала откатите дополнение рации, затем основной перевод: установщик сохраняет файлы, изменённые другими дополнениями.

В 0.3.1 RC исправлен откат при ошибках установки и восстановления языка. Сам перевод и 15 игровых патчей остались прежними; если 0.3.0 RC уже установлен, переустанавливать его ради этого выпуска не нужно. Используйте новый установщик для последующего восстановления. Подробности — в [AUDIT.md](AUDIT.md).

## Проверка

Для основного пакета проверены установка/откат и 10 сценариев Unity UI. Для дополнения рации прошли 56 проверок загрузки, таймингов и состояния интерфейса; остальные 190 строк субтитров сохранены. Эти проверки не заменяют полный игровой сеанс.

Для установщика 0.3.1 RC прошли 68 проверок на временных файлах: ошибки записи, проверка контрольных сумм и восстановление предыдущего состояния. Все 15 бинарных патчей повторно восстановлены в памяти из проверенных английских резервных копий и сверены по SHA-256. Игровое прохождение и независимая проверка Steam-сборки в этот аудит не входили.

Проверено на Windows x64, Unity 2017.3. Для BepInEx-плагинов используется BepInEx 5.4.23.5. Совместимость с другими версиями игры не гарантируется.
